# STM32U5A9BJY6QTR 208球位核对与修改说明

核对日期：2026年10月20日。对象：XWatch_Rev3.0 工程中的 STM32U5A9BJY6QTR 符号、原理图缓存和本地封装库。

## 结论

已核对全部208个球位的名称及全部208个封装焊盘的编号、位置和方向。原符号有两处名称错误，其余206个球位名称正确。原封装编号和错列排列方向正确，无缺失、重复或额外焊盘。修改后全部208球映射与ST数据手册及本机KiCad标准库对应符号一致。

## 核对依据

- ST官方数据手册 DS13543 Rev 3，2025年5月：<https://www.st.com/resource/en/datasheet/stm32u5a9bj.pdf>。
- 本地保存的 `datasheet_lcsc.pdf` 来自工程原有数据手册链接 <https://atta.szlcsc.com/upload/public/pdf/source/20250623/A58E0F9B416F8A9399264DA35C477010.pdf>，文件为同一版389页ST原厂手册。ST站点直接下载未完成，使用此镜像提取并与官方在线内容核对关键页。
- 第112页图19：WLCSP208 DSI SMPS顶视球位图。A行使用偶数编号，从A2起，并非完整矩形矩阵或从A1开始。
- 表27：WLCSP208 DSI SMPS列，提取全部208球的名称。逐行核对结果见 `208球位核对明细.csv`。
- 第376至378页图109及表169、170：封装机械尺寸及焊盘建议。
- 本机KiCad 10标准库 `MCU_ST_STM32U5:STM32U5A9BJYxQ`：208个球位名称独立比对，全部与ST一致。该通配型号对应本器件封装系列；温度及包装后缀不改变球位映射。
- 本机标准封装 `Package_CSP:ST_WLCSP-208_5.38x5.47mm_Layout26x16_P0.35mm_Stagger`：核对208个焊盘坐标及编号。

## 已修改内容

| 项目 | 修改前 | 修改后 |
|---|---|---|
| N24球名称 | PH0-OSC_IN | VREF- |
| N26球名称 | PH1-OSC_OUT | VSSA |
| 符号电气类型 | 全部208脚为passive | 与KiCad标准符号逐球一致；修改188脚，20脚保留passive |
| 铜焊盘直径 | 0.192 mm | 0.210 mm |
| 阻焊开口 | 未单独设定 | 单边扩展0.0325 mm，开口直径0.275 mm |
| 锡膏开口 | 未单独设定 | 单边扩展0.0125 mm，开口直径0.235 mm |
| 焊盘坐标 | 存在小于1微米的舍入差异 | 对齐KiCad标准封装精确坐标 |
| 焊盘形状 | 等长等宽oval | circle |

电气类型遵循KiCad标准符号，而非把所有电源相关引脚一律设为输出。例如VDD11属于可切换LDO/SMPS供电架构，其标准库类型为power_in。保留原符号的三个单元、引脚位置和实例UUID，避免改变现有连接。

更新的工程文件共4个：

- `XWatch_Rev3.0.kicad_sym`。
- `MCU_IO.kicad_sch`中的该器件缓存符号。
- `MCU_PWR.kicad_sch`中的该器件缓存符号。
- `XWatch_Rev3.0.pretty/STM32U5A9BJY6QTR.kicad_mod`。

## 验证结果和边界

- 符号208脚，球位集合完整、唯一；全部名称映射通过。
- 封装208焊盘，编号集合完整、唯一；与标准封装坐标一致，顶视方向正确。
- 两张原理图中的缓存与工程库修正结果一致。
- KiCad 10命令行成功读取修正后的原理图并导出网表和9张SVG；成功读取并导出修正后的封装SVG。已检查相关原理图和封装渲染图。
- 修改前后487组网表节点连接关系完全一致；两处更名只改变未连接网络的显示名称。没有重新布线或改接网络。
- ERC修改前554项，修改后591项，净增加37项。此前全部passive的设置掩盖了供电及输入未驱动问题，恢复电气类型后会被检出；本次未用PWR_FLAG或无连接标记掩盖这些问题。完整报告为 `erc_before.json`、`erc_after.json`。
- U15的N24 VREF-、N26 VSSA当前均未接线，M23/M25高速晶振脚也未接线。需要在后续电路设计中完成模拟地及HSE连接，当前工程不能视为通过电气检查的可投板版本。
- U15A电源单元已位于图框左侧并有部分内容在页外，U1旧主控电路也仍保留。这是修改前已有的编辑状态，本次没有移动符号或完成旧主控替换。
- 现有PCB仍含STM32U5G9NJH6Q的U1实例，没有STM32U5A9BJY6QTR实例。本次因此未改PCB文件；今后将U15更新到PCB时，应使用已修正的Rev3.0本地封装。库级修正不等于PCB已经完成器件替换。
- 本次不验证PCB走线、层叠和工厂对0.35mm WLCSP的最终可制造性；0.210mm焊盘及开口采用ST推荐尺寸，钢网仍需由SMT工程审核。
